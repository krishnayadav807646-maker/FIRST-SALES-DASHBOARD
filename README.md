# My First Excel Project: Sales Dashboard & Analysis

Hi! This is my first Excel project. I built it to learn how raw data can be turned into useful summaries, interactive reports, and practical business decisions.

The folder contains four Excel workbooks. Together, they cover lookup formulas, PivotTables and charts, a sales performance dashboard, and what-if analysis with Scenario Manager and Solver.

## Project files

### 1. `Excel - Sales Performance Dashboard.xlsx`
This is the main sales analysis workbook. It contains 9,800 sales records with order dates, customers, segments, regions, products, categories, and sales values. The workbook includes summaries and charts for:

- Sales trends over time
- Sales by region and state
- Product and category performance
- Sales by customer segment

Use the `Dashboard` sheet for the visual overview. The supporting sheets contain the source data and detailed summaries.

### 2. `Excel - Pivot Tables, Pivot Chart, Slicers.xlsx`
This workbook uses shipping and order data to practise organizing information with PivotTables, PivotCharts, and slicers. It includes a `Shipping Data` sheet, a `Main Pivots` report, and separate account-manager summaries. The source sheet also tracks order details such as priority, customer type, product, shipping method, and dates.

### 3. `Excel - LOOKUP, INDEX, MATCH, SUMIFS.xlsx`
This workbook demonstrates how Excel formulas can help prepare a customer quote for network equipment. It connects a customer quote to an international price list and a discount matrix. The examples use `VLOOKUP`, `INDEX`, `MATCH`, `SUMIFS`, and `SUBTOTAL` to retrieve product details, apply customer discounts, and summarize costs by installation location.

### 4. `Excel - Scenario Manager, Solver (Data Modeling).xlsx`
This workbook is a project-costing model for producing software manuals. It estimates effort, staffing duration, salaries, costs, revenue, and projected profit. The scenario summaries compare different prices and staffing/work schedules to show how changing assumptions can affect the result.

## What I learned

- Organizing raw data so it can be analysed
- Using formulas to look up and combine information
- Summarizing large tables with PivotTables
- Presenting findings with charts and a dashboard
- Exploring business decisions by changing assumptions

## How to explore the project

1. Open `Excel - Sales Performance Dashboard.xlsx` and start with the `Dashboard` sheet.
2. Visit the supporting sheets to see how sales summaries are organized.
3. Open the PivotTables workbook to explore order and shipping reports.
4. Review the lookup workbook to see how a quote is calculated from product and discount tables.
5. Open the data-modeling workbook to compare the saved scenarios.

Some workbooks contain Excel features such as PivotTables, slicers, or Solver/Scenario Manager summaries. For the best experience, open them in Microsoft Excel. If the source data is changed, refresh the PivotTables and charts in Excel to update their summaries.
